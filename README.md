# Adicionando o Pattern Observer neste fork

Este fork tem por objetivo adicionar o pattern Observer para um dos desafios de projeto do Bootcamp "Desenvolvimento Java com IA"

## Sobre o Padrão Observer

Observer (também conhecido como Listener ou Event Listener). Esse padrão é bem utilizado em cenários onde é necessário notificar automaticamente partes do sistema quando ocorre uma mudança de estado em algum objeto.

### Vantagens do Observer 

Desacoplamento: O serviço que cadastra clientes não precisa conhecer os detalhes sobre o que acontece após o cadastro.

Extensibilidade: Você pode adicionar novos listeners sem modificar o código existente.
